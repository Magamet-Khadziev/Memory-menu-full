# MEMORY - Цифровое меню кафе

## 📋 Как обновлять меню

### Добавить новое блюдо
1. Откройте файл в папке `js/data/` для нужной категории
2. Добавьте новый объект в конец массива:
```javascript
{
    id: 'уникальный-идентификатор-блюда',
    name: 'Название блюда',
    description: 'Краткое описание',
    composition: 'Ингредиенты',
    volume: 'Объём или вес',
    price: 280,
    image: 'images/категория/название.jpg'
}
